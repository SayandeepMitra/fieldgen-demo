Recipe for financial
Grain: One row per FinwireFIN financial report record: a company's financial results for a specific year and quarter (company × fi_year × fi_qtr).
Combine: none
Branch b1:
  FROM FinwireFIN AS fin
Decisions: joins: []; stacked: False; deduplicated: False; aggregated: False
Assumption: The matcher is noisy and maps many target fields to many source columns; only the semantically correct FinwireFIN columns are used: CoNameOrCIK for company, Year/Quarter/QtrStartDate for the period, and Revenue/Earnings/EPS/DilutedEPS/Margin/Inventory/Assets/Liabilities/ShOut/DilutedShOut for the measures.
Assumption: All FinwireFIN rows have RecType = 'FIN', so no RecType filter is required.
Assumption: sk_companyid is sourced from CoNameOrCIK and resolved to the dimcompany surrogate key in a later formula step; no join to dimcompany is performed because no link is supplied and dimcompany is not available as a source table in this recipe step.
Assumption: Each FinwireFIN row represents one distinct financial report, so one source row produces one target row; no stacking, deduplication, grouping, or aggregation is required.
Assumption: No generated surrogate key is required in this recipe; sk_companyid is a foreign key sourced from CoNameOrCIK, not a key to be numbered here.
