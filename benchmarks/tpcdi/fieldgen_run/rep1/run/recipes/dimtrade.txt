Recipe for dimtrade
Grain: one row per trade (Trade.T_ID)
Combine: none
Branch b1:
  FROM Trade t LEFT JOIN StatusType st ON t.T_ST_ID = st.ST_ID LEFT JOIN TradeType tt ON t.T_TT_ID = tt.TT_ID
Decisions: joins: ['left join StatusType on trade status id', 'left join TradeType on trade type id']; stacked: False; deduplicated: False; aggregated: False
Assumption: Trade.T_ID is the natural key for dimtrade grain.
Assumption: Status and type descriptions are obtained from StatusType and TradeType via many-to-one links.
Assumption: TradeHistory is not required for the dimtrade grain; close date/time are left nullable.
Assumption: Surrogate keys for broker, date, time, security, company, customer, account are resolved in a later step and are not part of this recipe.
